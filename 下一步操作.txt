步骤1: 安装Git (如果尚未安装)

2. 运行安装程序，使用默认设置
3. 安装完成后重启命令提示符
4. 验证安装: git --version

步骤2: 创建GitHub仓库 (如果尚未创建)
----------------------------------------
1. 登录GitHub: https://github.com
2. 点击右上角 "+" → "New repository"
3. 填写信息:
   - Repository name: tool-zs-02
   - Description: (可选)
   - 选择 Public 或 Private
   - 不要初始化README、.gitignore或许可证
4. 点击 "Create repository"

步骤3: 生成Personal Access Token (PAT)
----------------------------------------
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 点击 "Generate new token (classic)"
3. 填写 Note: "tool-zs-02 push access"
4. 勾选 "repo" 权限
5. 点击 "Generate token"
6. 复制生成的token (重要: 只会显示一次)
